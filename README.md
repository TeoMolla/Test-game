# Dragon Ball Auto-Battle RPG Prototype — Starter Folder

## What's in here
- `PROMPT.md` — the full build prompt for Claude Code. Paste its contents into a Claude Code session opened at the root of this folder.
- `reference/afk-arena/` — 4 reference screenshots from AFK Arena (battle screen, hero roster, hero detail — stars, hero detail — stats/gear). The prompt tells Claude Code to look at these directly for UI/layout reference. Reskin everything with Dragon Ball theme — these are structure references only.

## How to use
1. Move this folder into your dev workspace.
2. Open Claude Code in that folder.
3. Paste the contents of `PROMPT.md` as your first message.
4. Claude Code should ask clarifying questions first — answer those, then let it build.
5. Serve it locally (e.g. `npx serve` or Python's `http.server`) and open the LAN address on your iPhone browser to test.
